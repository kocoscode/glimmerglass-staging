Inside Framer

Artwork in.
Component out.

You drew an animation with a see-through background. Putting it on a website usually goes badly: a box shows up, the file is huge, or it only works in one browser. Glimmerglass fixes that. It turns your transparent animation into a versatile Framer component, with the player and the video files already connected. Your artwork keeps the transparency it had. We don’t create transparent files - we simply transcode transparent files for ease of use on the web.

The Glimmerglass plugin is not on the Framer Marketplace yet. This guide describes how it works; the install link will be added when it is live.

  1. Open Glimmerglass in your Framer project.The plugin uses the license key from your Gumroad receipt email. Paste it in once in each browser profile you use.
  2. Drop in your transparent animation.A file, a folder of frames or a .glim you already made. The full list is below. You don’t need an existing component or a player file.
  3. Adjust the settings.Choose the component name, quality and description. PNG sequences offer frame-rate choices; timed sources retain their own timing. Changing quality updates estimates without converting.
  4. Press Create Component.Your files are uploaded for conversion. Glimmerglass then uploads the finished media to your Framer project, creates the Code File and places the component on your page, in the frame you selected or on the page if nothing is selected. It moves and edits like anything else in Framer.
  5. Inspect and use it.Check the encoded result with Size Preview and the background controls. Open Framer Preview to see it move. The canvas shows a still picture while you design. Download is available if you also want the portable bundle.

What goes in

One animation file, or a pile of frames. Any of these:

  • MOV (ProRes 4444 works great), MP4 or WebM with transparency
  • APNG or animated PNG
  • Animated WebP
  • GIF
  • A folder of PNG frames, or of WebP frames. Pick one kind and tell the plugin the frame rate.
  • A .glim file you already made. That’s Glimmerglass’s own format: one file with every size inside, ready to drop straight in.

Limits: 256 MB of upload, 600 PNG frames, up to 120 seconds, and 16 megapixels per frame. Very long, very big clips can run out of time.

Why a .glim is worth it

A .glim is one file that holds your animation at several sizes. The player gives every visitor the one that fits their device. That buys you:

  • No picking this format for that browser, or testing in each one.
  • No unique files per responsive slice.
  • No settings drifting between files.
  • Tag it once for SEO, not once per file.
  • Phones never download the desktop-sized version.
  • A greater degree of authorship over your work.
  • Less brittleness, everywhere.

What you can change in Framer

Resize the component however you like. Then tweak it in the properties panel:

  • Play: always, on hover, or when it scrolls into view. On a phone, hover becomes tap.
  • Hover Area: when it plays on hover, choose the animation itself or the frame around it.
  • Click to Pause: let visitors click to play and pause.
  • Speed: anywhere from 0.25x to 4x.
  • Loop: on or off.
  • Controls: show a play bar, or don’t.
  • Fit and Position: contain, cover or fill, and where it sits in the frame.
  • Background: add a color behind it if you want one.
  • Alt Text: describe it for screen readers, and creepy crawlers.

The finished component stands on its own. No calls home, no dependency, nothing to break later.

When something interrupts creation

Conversion finished, but insertion failed

Keep the plugin open and use Retry. Glimmerglass retains the converted files and successful uploads during that session. If the error says a file already exists, the plugin uses a unique name to preserve your existing work.

“This origin is not allowed”

The conversion service hasn’t accepted the address this plugin is running from. This is a service configuration problem, not a problem with your PNG folder. Send support the error and whether you opened a Marketplace or review version; do not send a license key.

The service is busy or unavailable

Try again later. Cloud conversion needs a working connection and available capacity, even when your saved license remains unlocked. An already-created component does not depend on the converter service to play.

The file is too large

The hosted converter accepts up to 256 MiB of source files, 600 frames, 16 megapixels per frame and 120 seconds of animation. Export a shorter source or reduce its original dimensions, then try again.

License help

A license key unlocks the Glimmerglass plugin for Framer. Lifetime license, one payment. Your license is for you, on your own browsers and computers. There's a soft limit of 5 browsers to catch shared keys - normal use never touches it.

To start, buy the key on Gumroad. It arrives by email. Then install the plugin from the Framer Marketplace (free to install) once it is live, open it, and paste in your key.

No refunds. It costs less than a McDonald’s combo meal.

Where do I find my license key?

It is in the receipt email Gumroad sends after your purchase: four groups of eight characters. If you cannot find that email, look the key up at gumroad.com/license-key-lookup.

How do I use it on another browser or computer?

Enter the same key there. Each browser profile remembers the key for itself. To take the key off a shared computer, choose Remove license from this browser in the plugin.

I cleared my browser data and the plugin asks for my key again

Enter the key again; nothing else is needed. Never post your complete key publicly.

Why was my license slowed or paused?

A key that appears on many new devices in a short time, or starts conversions at an unusual rate, is slowed or paused, because that is what a publicly shared key looks like. Ordinary use on your own devices does not reach these limits. Browsers already using the key keep working. If this happens to you, contact support.

Can I work offline?

A previously validated license can remain unlocked for up to 14 days during a validation outage. Creating a new component still requires the conversion service and Framer uploads. Existing components keep working from the media stored in your project.

Does an update overwrite my component edits?

No. New creations use a unique Code File name instead of replacing an existing file. Keep your edited component until you have checked the new one.
