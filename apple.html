Make your first component.

The Apple app converts on your device. Your source files stay with you, and conversion works without an internet connection.

  1. Add your artwork.Choose a file or a folder of numbered PNG frames. You can also select several PNG files together. Try the included sample to get familiar with the controls.
  2. Set the name and quality.The name becomes your component’s filename. Moving Quality changes the estimated file sizes; it does not start a conversion.
  3. Check the timing and preview.Timed files keep their source timing. For a PNG sequence, choose a frame rate. A sequence of 24 frames lasts two seconds at 12 fps, or one second at 24 fps. Change the preview background to inspect transparency.
  4. Create Component.Keep the app open while it creates independent sizes from the original artwork. You can cancel. After conversion, Size Preview plays the selected output so you can inspect the actual result.
  5. Download or share.Download saves a ZIP to the location you choose. Share Component sends the complete component file to your chosen app or device.

Put it in Framer

On a computer, open your Framer project. Under Assets, create a Code File. Open the exported .tsx in a text editor, copy its entire contents into the Code File, then place that component on the canvas. The file includes the animation and player.

The Apple app doesn’t connect directly to your Framer account. If you prefer automatic placement in the current project, use the Framer plugin.

Use the download elsewhere

Unzip the download to find the transparent videos, posters, preview and player. Keep its files together. The included instructions explain how to use the animation on a website. Upload both video formats so compatible browsers can choose between them.

Artwork that works well

Start with a transparent MOV (including supported HEVC alpha or ProRes 4444), WebM, APNG, GIF, or equally sized PNG frames. Support for a particular video codec depends on the system decoder. A file ending in .mp4 does not necessarily contain transparency.

Glimmerglass preserves alpha; it does not cut out a solid background. If an input is opaque, the app explains this and asks before continuing.

Long animations and large frames require more memory and free space. For your first conversion, use a short clip. If a conversion is interrupted, reopen the app and try again with a shorter source or smaller original dimensions.

Common questions

Why doesn’t Quality change the preview immediately?

Before conversion, you see a source preview. Quality changes estimates only. Press Create Component to see the actual encoded quality. Changing settings after a conversion returns you to estimates until you create again.

Where are my downloads?

Completed conversions stay in the app’s Documents folder. Use Previous Downloads to reopen and export them. On iPhone and iPad you can also browse the Glimmerglass folder in Files. Download saves a separate copy wherever you choose.

What should I put in the description?

Describe it for screen readers, and creepy crawlers.

Why are the file sizes different from the estimate?

Estimates are planning aids. Actual size depends on the frames, timing, dimensions and encoding settings. The app displays measured sizes only after conversion.

Can I change the source frame rate?

When timing is known, the app preserves it. Untimed PNG frames need a frame rate: choose one to control the duration and playback speed.

Still stuck?

Include your device, operating-system version, source format and the exact error. You don’t need to send your artwork unless we ask for a sample.
